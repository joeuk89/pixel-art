# Pixel Art Scenes

A personal web app that generates cosy, animated pixel-art scenes with matching sound, to be left open in a browser tab.

## Language

**Scene**:
One generated bundle: the artwork, its animation, its Soundtrack and the Prompt that made it.
_Avoid_: Wallpaper, image, video, artwork (for the whole bundle)

**Prompt**:
The text typed to request a new Scene. Kept in the Scene plan; never shown on the site.
_Avoid_: Request, query

**Description**:
The Director's two-or-three-sentence account of a finished Scene, written from the Prompt and what was generated. The Viewer's info panel and link previews show it.
_Avoid_: Caption, blurb, summary

**Viewer**:
The browser page that plays one Scene, including fullscreen.
_Avoid_: Player, app, canvas (for the page)

**Soundtrack**:
The music and ambient sound of one Scene.
_Avoid_: Audio, music (when ambient sound is included), track

**Share link**:
The public permalink that plays one Scene for anyone, with no login.
_Avoid_: Share, export, embed

**Element**:
One generated, reusable visual piece of a Scene, such as a lamp or a skyline, kept in the Element library.
_Avoid_: Asset, sprite, object, part

**Element library**:
The tagged collection of Elements that new Scenes shop from before anything is generated.
_Avoid_: Asset store, sprite sheet, catalogue

**Backdrop**:
An opaque Element that fills the back of a Scene, or the opening it shows through, made at the size it covers and placed once.
_Avoid_: Background, bg, panorama

**Seamless texture**:
An Element with no landmarks whose left and right edges join, so it may repeat across a Scene's width.
_Avoid_: Tile, tileable, pattern

**Gallery**:
The Viewer's list of generated Scenes.
_Avoid_: Library (for Scenes), feed, index

**Director**:
The Claude Code skill that turns a Prompt into a Scene plan and drives the pipeline that produces the Scene.
_Avoid_: Generator, orchestrator, agent

**Scene plan**:
The structured description of a Scene the Director writes before any Element or Soundtrack is generated.
_Avoid_: Manifest, config, spec, scene file

**Layer**:
One draw-ordered slice of a Scene; a Scene is drawn layer by layer, first to last.
_Avoid_: Depth, z-index, plane (that is how far away a Layer sits)

**Plane**:
How far from the viewer a Layer sits: far, mid or near. Far Planes fade toward the sky or the dark; near Planes frame the Scene.
_Avoid_: Depth, layer, distance (that is for sound)

**Placement**:
One Element put at a position in a Layer.
_Avoid_: Instance, sprite, object

**Stage**:
The forced-perspective geometry of a Scene: a back rectangle, a vanishing point and a viewing distance, which give the floor its depth. Indoors and outdoors alike.
_Avoid_: Camera, room, perspective, set

**Room shell**:
The walls, floor and ceiling of an interior, drawn from the Stage in perspective with flat colour and a few lines.
_Avoid_: Room, box, background, walls

**Surface**:
One face of a Room shell: the back wall, floor, ceiling, left or right wall.
_Avoid_: Wall (for any face), face, plane, side

**Opening**:
A window or door cut from a Surface, through which far Layers show, with an optional frame.
_Avoid_: Hole, cut-out, window (for any opening)

**Feature**:
A Placement fixed to a Surface, such as a painting, wall light or rug, generated square-on and fitted to the Surface's perspective.
_Avoid_: Decoration, decal, wall prop

**Primitive**:
One code-driven animation effect the Viewer runs on a Scene, such as rain, lamp glow, steam or twinkle.
_Avoid_: Effect, animation, shader

**Poster**:
The still image that stands in for a Scene in the Gallery and in Share link previews.
_Avoid_: Thumbnail, screenshot, cover

**Palette**:
The named, ordered set of colours a Scene and its Elements are locked to.
_Avoid_: Colour scheme, theme, swatch

**Ramp**:
The darker and lighter steps each Palette colour moves to under light, with separate lighter steps for warm and cool light.
_Avoid_: Shade, gradient, colour ramp

**Light**:
A source of illumination the Viewer applies over a Scene: the ambient level, a point such as a lamp, or a beam such as a sun shaft.
_Avoid_: Lamp, glow, lighting effect

**Halo**:
The smooth, full-colour glow a point Light may add around itself; the only lit pixels allowed off the Palette.
_Avoid_: Bloom, glow, aura

**Variant**:
One named lighting of a Scene, such as dusk, night or rain, over the same Elements and Placements; the first is the default.
_Avoid_: Mode, preset, version, theme

**Emissive colour**:
A colour in one Element that lights itself and is never darkened by its Ramp.
_Avoid_: Glowing colour, self-lit, unlit

**Element record**:
The metadata kept beside an Element: what it is, how it was made and which Palette it is locked to.
_Avoid_: Sidecar, metadata file, manifest

**Finish**:
How an Element is made: a local finish is drawn by the local pixel engine, exact and plainer; a service finish is generated by an image service, richer in detail and shading.
_Avoid_: Quality, mode, engine choice

**Ambient loop**:
One seamless looping ambient sound in the Sound library, with its licence recorded.
_Avoid_: Sample, sound file, clip

**Sound library**:
The collection of Ambient loops the Director shops from for a Soundtrack.
_Avoid_: Sound bank, sample pack

**Attempt**:
One generation call for one Element or Frame strip, judged by the Quality gate; an Element may take several Attempts.
_Avoid_: Try, run, call, generation (for the judged unit)

**Frame strip**:
The row of frames that animates one Element, kept beside its still in the Element library; frame 0 is the still itself.
_Avoid_: Sprite sheet, animation, GIF, strip (alone)

**Quality gate**:
The checks every Attempt must pass before its Element enters the Element library: programmatic checks first, then the Director's visual check.
_Avoid_: Validation, QA, review (for the whole gate)

**Style anchor**:
The first Element generated for a Scene, passed as the style image to every later Attempt in that Scene so they read as one hand.
_Avoid_: Reference image, style image (for the Element itself), seed image

**Distance**:
How close an ambient sound sits to the viewer: near, mid or far. Sets how loud and how muffled it plays.
_Avoid_: Layer (for sound), tier, bus, plane

**One-shot**:
A single ambient sound event, such as thunder or an owl, that a Scene fires now and then instead of looping.
_Avoid_: Trigger, event, sample, stinger

**Scale**:
The pixels-per-metre that fixes how large a prop is drawn: set at the back of the Stage, and separately for a far Layer beyond it; a prop standing on the floor takes the Scale of its depth.
_Avoid_: Zoom, resolution, pixel density (that is the house tier), size (for the Scene-wide value)

**Concept**:
The Director's short statement of a Scene before it decomposes or shops: setting, time, weather, light source, focal point and the specific details the Prompt asked for.
_Avoid_: Brief (that is the per-Element text sent to the image service), idea, vision, summary

**Plan gate**:
The one point where the Director stops for the owner's yes before any Element or Soundtrack is generated, showing the Scene plan and its estimated cost.
_Avoid_: Approval, checkpoint, review, confirmation
